# NewEra Solution premium EdTech website

## Goal
Build a polished, conversion-focused public website that positions NewEra Solution as a modern technology learning company, with strong course discovery, detailed course pages, and a validated counselling enquiry flow.

## Experience
- Create a dark premium design system using near-black, navy, electric blue, violet, cyan, restrained glass surfaces, crisp typography, and subtle motion.
- Build a sticky navigation, immersive hero, editable trust strip, three course showcases, feature grid, learning timeline, technology ecosystem, project gallery, AI-era feature, career section, clearly labelled sample testimonials, FAQs, final call-to-action, and footer.
- Add a lightweight interactive React Three Fiber hero core with nodes, orbital rings, particles, pointer response, reduced-motion support, simplified mobile rendering, lazy loading, and a non-WebGL visual fallback.
- Keep content concise and distinctive; avoid fake outcomes, partner claims, student counts, or contact details.

## Courses and conversion
- Store courses, curriculum, projects, FAQs, site settings, metrics, and contact placeholders in structured configuration.
- Create dedicated SEO-ready detail pages for Full Stack, AI Automation, and Data Science & AI.
- Add accessible enquiry forms with client and server validation, course-aware confirmation, clear loading/error states, and prominent counselling calls-to-action.
- Keep phone, email, WhatsApp, location, and social URLs configurable and show neutral unavailable states until real details are supplied.

## Data
- Enable Lovable Cloud and save enquiries securely with row-level access controls; public users may submit, but cannot read submissions.
- Seed editable public course/contact/testimonial content only where useful, while keeping the initial website resilient through typed local configuration.

## Quality and verification
- Add unique metadata, Open Graph/Twitter fields, canonical URLs, semantic headings, structured data, alt text, and accessible interactions per page.
- Verify the production preview, 3D rendering, mobile and desktop layouts, navigation, course pages, form validation/submission, reduced motion, and console/runtime health.

## Technical details
- TanStack Start + React 19 + TypeScript + Tailwind v4.
- React Three Fiber/Drei for the procedural 3D core; Motion for selective interface animation.
- React Hook Form + Zod for validation; protected server functions and Cloud persistence for enquiries.
- Reusable section, button, course, form, and visual components; no secrets in browser code.
